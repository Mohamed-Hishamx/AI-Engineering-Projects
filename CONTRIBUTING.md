# How to Add a New Case Study

This repo is a living portfolio, not a one-time submission. New work gets added here as it happens.

## Where it goes
Each case study is its own subfolder: `cli-to-saas/0X-project-name/`

## Steps
1. Create the subfolder for the new project.
2. Write a `README.md` inside it with exactly three sections:
   - **Problem** — what pain this solves and for whom
   - **What I did** — stack and key technical decisions (3-5 bullets)
   - **What came of it** — the concrete outcome
3. Push the code and README.
4. Update this repo's top-level README project index with a one-line entry linking to the new folder.
5. If the work is client-facing (Apex Cycle), cross-post a short version to LinkedIn.
